# Ecological_Memory_CHWD_GPP
Code for compound heatwave–drought identification, machine-learning-based GPP modelling, and attribution of terrestrial GPP anomalies.

## Overview

This repository contains the core analysis code used to:

1. identify compound heatwave–drought (CHWD) conditions;
2. build pixel-wise machine-learning models of monthly GPP;
3. quantify concurrent climate effects (CCE), lagged climate effects (LCE), vegetation growth carryover (VGC), and individual climatic-driver contributions.

The analyses focus on China, Europe, and the United States during the 2022 CHWD events.
